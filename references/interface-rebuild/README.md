# Interface rebuild evidence (2026-09-29)

Captures from real Electron (`VITE_NESTED_DEBUG=1` build, `scripts/scene-debug.mjs`, debug project: living room 7 × 5.5 × 2.9 m, prototype sofa, coffee table, floor lamp, rug). Window 1427 × 727 CSS px at device pixel ratio 2; canvas 2094 × 1342 device pixels. These show the first implementation of `references/interface-target/`, not an approved rendering quality.

- `workspace-shop.png`: whole window, Shop tab, eye level (`NESTED_DEBUG_FULL=1`).
- `eye-level-selected.png`: eye level with the sofa selected (frame, tag, selected-piece panel).
- `overview.png`: dollhouse overview; the near wall is cut away because the camera is outside it.
- `corner.png`: corner view, standing inside the closed room.

Known visual shortfalls visible here: dark, brownish ceiling; procedural furniture (corrugated coffee-table top, plain rug); painted window view.
